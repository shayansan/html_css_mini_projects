# HTML & CSS Mini Projects

This repository contains a collection of small HTML and CSS exercises created during my early learning phase in web development.

## Purpose
The goal of these mini projects was to understand and practice:
- Basic HTML structure
- CSS styling fundamentals
- Layout concepts (forms, cards, headers)
- Reusable UI components

## Content
The projects are organized into folders such as:
- headers
- cards
- forms
- small UI experiments

Each folder represents a focused practice on a specific concept.

## Status
This repository is **archived** and no longer actively maintained.
It represents foundational learning before transitioning toward security-focused topics.

## Notes
These exercises helped build a basic understanding of front-end structure, which is useful later when studying web security concepts.
